This roadmap is capability-based, not calendar-based. A documented design is not the same as a working implementation.

## Stage 5 — Automation and evaluation
- [ ] Add tests and structured logs.
- [ ] Add repeatable evaluation datasets for scripts, diagrams and renders.
- [ ] Automate stable low-risk operations.
- [ ] Connect first-party analytics through authorised exports or official APIs.
- [ ] Keep publishing and final approval human-controlled.

## New architecture decisions from external repository review
- Prefer deterministic code-rendered educational scenes; use generated footage as optional ingredients.
- Use scene-level production plans, a storyboard gate, an opening pilot, frame/contact-sheet QA and explicit human approval.
- Use semantic diagram selection and each brand's own design profile.
- Keep media providers replaceable through adapters; do not hardwire an external generation API.
- Do not use unofficial Instagram bots, private APIs, session scraping or engagement automation.
- Do not reuse PolyForm Noncommercial or unlicensed upstream assets in commercial production without permission.

## Completion rule

A task is complete only when its output exists, has been tested or reviewed, and its limitations are documented. A checked box should represent evidence, not intention.
