# Creator OS Roadmap

This roadmap is capability-based, not calendar-based.

## Stage 1 — Foundation
- [x] Create central Creator OS repository.
- [x] Define the three brand boundaries.
- [x] Document system architecture and operating workflow.
- [ ] Confirm each brand's final visual and editorial configuration.
- [ ] Agree content ID and folder conventions across repositories.

## Stage 2 — Manual repeatable workflow
- [ ] Run one complete content item through the process for each brand.
- [ ] Refine research, brief, script, storyboard, and production templates.
- [ ] Record bottlenecks and review time.

## Stage 3 — Agent skills
- [ ] Topic researcher
- [ ] Brand router
- [ ] Scriptwriter
- [ ] Fact-checker
- [ ] Storyboard planner
- [ ] Publishing auditor

## Stage 4 — Production engine
- [ ] Define a shared scene schema.
- [ ] Build reusable Remotion components.
- [ ] Add media validation and export utilities.
- [ ] Document Resolve handoff and project templates.

## Stage 5 — Automation and evaluation
- [ ] Add tests and structured logs.
- [ ] Add repeatable evaluation datasets.
- [ ] Automate stable low-risk operations.
- [ ] Keep publishing and final approval human-controlled.

## Completion rule

A task is complete only when its output exists, has been tested or reviewed, and its limitations are documented. A checked box should represent evidence, not intention.
