# Operating Workflow

## Workflow states

`inbox → researching → validated → briefed → writing → fact-check → storyboard → production-ready → producing → review → approved → scheduled → published → analysed`

A state change should have a clear completion condition. Do not mark work complete because an agent generated a file.

## Step 1 — Intake
Record the idea, where it came from, the audience question, date, and any initial evidence.

## Step 2 — Research
Gather primary and credible independent sources. Record the exact claims each source supports. Note missing evidence and disagreements.

## Step 3 — Opportunity evaluation
Assess audience relevance, evidence, differentiation, timing, production effort, and fit with a brand. Reject ideas that are merely trending but offer no useful angle.

## Step 4 — Brand routing
Use the brand's core editorial question. If the topic is shared, define separate treatments before scripting.

## Step 5 — Brief
Define target audience, problem/question, promise, learning or practical outcome, scope, key claims, sources, format, and CTA.

## Step 6 — Script and fact-check
Write a coherent narrative. Attach evidence to factual claims. Label interpretation and uncertainty. Review the script before visual production.

## Step 7 — Storyboard and production plan
Break the story into scenes. Specify narration, on-screen text, visual direction, timing, assets, and source dependencies.

## Step 8 — Production
Create or capture assets. Keep original media outside Git. Track generated and licensed assets in the manifest.

## Step 9 — Editing
Assemble in DaVinci Resolve. Use Remotion for reusable programmatic motion graphics where it is a better fit. Use Flow for supporting generated clips when appropriate.

## Step 10 — Quality review
Check factual accuracy, brand fit, rights, privacy, sound, captions, visual readability, aspect ratio, export settings, and final runtime.

## Step 11 — Publishing
Prepare platform-specific title, description, caption, tags where relevant, thumbnail/cover, subtitles, and source disclosures.

## Step 12 — Learning
Record performance, audience feedback, unexpected outcomes, and changes to make next time.
