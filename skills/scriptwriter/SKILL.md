# Scriptwriter

Create a platform-appropriate script from an approved brief and evidence pack. Confirm audience, format, duration and promise; identify one central idea; build a clear narrative; write a specific honest hook; use examples; attach source IDs to factual claims; preserve caveats; end with a meaningful takeaway and relevant CTA.

Never invent anecdotes, test results, statistics, quotes or product capabilities. Follow the brand's editorial role.
