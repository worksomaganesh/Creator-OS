# Fact-checker

Extract verifiable claims and map each to underlying sources. Check names, dates, numbers, quotes, comparisons and causal language. Flag unsupported, outdated, ambiguous or overgeneralised claims. Distinguish fact, attribution, analysis and speculation.

Return a table: claim | evidence | status | issue | recommended action. Statuses: verified, partially supported, unsupported, contradicted, outdated, needs attribution. Never verify a claim based only on an AI-generated summary; inspect the source.
