# Brand adapters

Each brand adapter contains brand-specific configuration consumed by shared workflows. The full editorial strategy and content library remain in the brand's own repository.

| Adapter | Editorial responsibility | Repository |
|---|---|---|
| TECHENIGMASTUDIOS | Explain technology and teach concepts | https://github.com/worksomaganesh/techenigmastudios |
| AI That Works | Demonstrate useful AI implementations | https://github.com/worksomaganesh/aithatworks |
| ContextAhead | Explain context and implications | https://github.com/worksomaganesh/contxtahead |

The configuration files here are starter summaries. Update them only when a brand decision is explicitly made. Do not silently lock proposed colours or undecided presenter formats.
