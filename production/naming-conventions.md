# Naming Conventions

Content IDs: `TES-YYYY-NNN`, `ATW-YYYY-NNN`, `CA-YYYY-NNN`.

Files use `CONTENT-ID_asset-description_v001.ext` (example: `TES-2027-001_script_v001.md`). Increment versions for meaningful revisions. Keep raw footage, generated clips, audio masters, proxies, Resolve projects, caches, review renders and exports in managed media storage; record references in the asset manifest.
